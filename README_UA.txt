Wonderworks — Devon Rex

Публічна GitHub Pages-копія макета Wonderworks для перевірки QR-переходу через домен github.io.

Основні сторінки:
- index.html — виставкова картка з QR;
- socials.html — міністорінка з клікабельними Instagram / TikTok / Facebook;
- print/print-card-front.html — друкований прев'ю-макет.

Тестова GitHub Pages адреса міністорінки:
https://l1fe1sgood.github.io/Wonderworks-devon/socials.html

Перед друком QR необхідно окремо перевірити системним Xiaomi Scanner, Google Lens / Android Camera та iPhone Camera.
